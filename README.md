# full-stack-skill

Agent prompt for a full stack application.

## Contents

- **[GOLDEN.md](./GOLDEN.md)** — 50 golden rules for frontend work: business, performance,
  assets, accessibility, security, SEO and code health. Each rule has a *Check* line.
- **[RUST.md](./RUST.md)** — 45 golden rules for Rust backends: toolchain, async discipline,
  error handling, timeouts, shutdown, observability, security, build profile and data.

Both are grounded in primary sources — web.dev / WCAG / OWASP for the frontend,
the Rust production-readiness literature for the backend — rather than opinion.
